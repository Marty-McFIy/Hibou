# Icones

35 icônes maison au trait (24 px, trait 1,75, bouts ronds). En interface : `<span class="hb-icone hb-icone--terminal"></span>` (masque CSS, couleur = `color`), tailles `--sm` 16, défaut 20, `--lg` 24, `--xl` 32 ; ou `Hibou.Icone('terminal')`. Toujours `aria-hidden` à côté d'un libellé ; seule, donner un `aria-label` au bouton. Fichiers SVG : `assets/Icones/`.
