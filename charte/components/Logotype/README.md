# Logotype

Symbole + nom en Fraunces 600. `Hibou.Logotype({taille})` : le nom mesure 82,5 % de la taille du symbole, l'écart un quart. Pour un fichier figé (document, impression) : `assets/Logos/hibou-logotype-sur-nuit.svg` ou `-sur-brume.svg`, texte vectorisé. Ne jamais recomposer le nom dans une autre police.
