# Contribuer

1. Une branche par sujet, une pull request vers `main`.
2. Le script `hibou` reste un seul fichier Bash : `bash -n hibou` doit passer.
3. Rien ne doit se télécharger à l'installation : tout passe par `hibou telecharger`.
4. Les textes (messages, docs) sont en français, ton sobre.
5. Les polices et ressources de la charte restent locales.

Les briques à faire sont listées dans la section « État » du [README](README.md).
