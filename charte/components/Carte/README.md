# Carte

Quatre niveaux de relief, toujours éclairés du haut : `--creuse` (enfoncé), défaut (`surface` + `relief-1`, posé), `--haute` (`relief-2`, soulevé), `--flottante` (`relief-3`, menus et fenêtres). `--vivante` se soulève au survol. `hb-entree` + `style="--i:n"` fait entrer les cartes en cascade (70 ms d'écart). Ne pas empiler plus de deux niveaux.
