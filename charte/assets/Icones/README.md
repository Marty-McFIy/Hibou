# Icônes

Jeu maison de 35 icônes au trait : grille 24 px, trait 1,75 px, bouts et angles ronds, aucun remplissage.

- Dans une interface, utiliser la classe `hb-icone hb-icone--<nom>` de `components/bundle.css` : l'icône prend la couleur du texte (`color`).
- Les fichiers SVG ci-dessous servent hors CSS (documents, maquettes). Ils sont à encre unique `#6B7690`, lisible sur `nuit` comme sur `brume` (≥ 3,5:1) ; changer l'attribut `stroke` pour une autre encre.
- Taille minimale 16 px. Tailles prévues : 16, 20 (défaut), 24, 32.
- Jamais d'émoji à la place d'une icône.

- `ecrire.svg` — Rédiger, modifier un texte.
- `document.svg` — Un document, un fichier texte.
- `dossier.svg` — Dossier, espace de travail.
- `terminal.svg` — Ligne de commande, `hibou start`.

- `modele.svg` — Un modèle, ses couches.
