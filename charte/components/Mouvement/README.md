# Mouvement

Les quatre courbes de mouvement, rejouées. Règles : `courbe-sortie` par défaut ; `courbe-ressort` seulement pour ce qu'on touche (pouce, bouton relâché, tête du logo) ; `courbe-veille` pour les boucles lentes. Durées : `duree-instant` (pression) → `duree-veille` (cycle). Rien ne bouge sans raison ; tout s'arrête sous `prefers-reduced-motion`.
