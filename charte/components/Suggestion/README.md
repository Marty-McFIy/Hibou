# Suggestion

Modifications proposées dans un texte : `hb-ajout` (fond `succes-doux`, soulignement `succes`), `hb-retrait` (fond `danger-doux`, barré `danger`). `data-etat="acceptee"` ou `"refusee"` sur `.hb-suggestion` replie ce qui part. Le barré et le soulignement portent le sens, pas la couleur seule.
