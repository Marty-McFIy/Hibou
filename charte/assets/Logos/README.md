# Logos

Le symbole est une tête de hibou vue de face : deux oreilles, deux yeux d'ambre, un bec. Il se construit dans un carré de 120 unités.

- `hibou-symbole-sur-nuit.svg` — Symbole pour fond sombre (`nuit`, `ardoise`). Tête `brume`, orbites `nuit`, iris `ambre`, bec `ardoise`. La version de référence.
- `hibou-symbole-sur-brume.svg` — Symbole pour fond clair (`brume`, blanc). Tête `nuit`, orbites `brume`, iris et bec `ambre`.
- `hibou-symbole-mono-brume.svg` — Une seule encre `brume`, yeux et bec évidés. Pour la gravure, le tampon, l'impression une couleur sur fond sombre.
- `hibou-symbole-mono-nuit.svg` — Une seule encre `nuit`, pour fond clair.
- `hibou-logotype-sur-nuit.svg` — Symbole + nom « Hibou » en Fraunces 600 vectorisé, encre `brume`. Le nom mesure 82,5 % de la hauteur du symbole, l'écart un quart.
- `hibou-logotype-sur-brume.svg` — Le même pour fond clair, encre `nuit`.
- `hibou-icone-app.svg` — Icône d'application 512 px : le symbole à plat sur une tuile de nuit en relief (lumière du haut, coins à 22,5 %). Le seul endroit où le logo porte une ombre.
- `hibou-favicon.svg` — 32 px : les yeux seuls sur une tuile `nuit`. À utiliser sous 24 px, là où le symbole entier ne tient plus.

Zone de protection : un diamètre d'œil (un quart de la largeur du symbole) sur chaque côté. Taille minimale du symbole : 24 px.
