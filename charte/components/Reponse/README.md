# Reponse

Une réponse qui s'écrit mot à mot (fondu + net, 45 ms par mot) pendant que le hibou est en `ecriture`. `Hibou.Reponse(texte)` découpe le texte ; en flux réel, ajouter chaque mot dans un `span.hb-reponse__mot`. Ton : calme, précis, tutoiement, phrases courtes ; Hibou dit ce qu'il a fait, pas ce qu'il ressent.
