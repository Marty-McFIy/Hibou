# Hibou 0.9.5

_22/11/2026_

Installer Hibou sans disque de transport. Détail et preuves : [journal des corrections](../../JOURNAL-CORRECTIONS.md) (F20).

## Démarrer

1. Télécharge `hibou-0.9.5.tar.gz` et `hibou-0.9.5.tar.gz.sha256` ci-dessous.
2. `sha256sum -c hibou-0.9.5.tar.gz.sha256 && tar xzf hibou-0.9.5.tar.gz && cd hibou-0.9.5`
3. **Hôte Proxmox connecté à Internet** : `sudo ./hibou en-ligne /var/lib/hibou/bundle` (prépare et installe tout).
   **Réseau isolé** : `./hibou telecharger` sur une machine connectée, disque de transport, puis `./hibou installer forge|doc|dev`.
4. Guide complet : [installation](../installation.md), [mise en production](../mise-en-production.md).

## Nouveautés

- **`hibou en-ligne`** : lancée sur l’hôte Proxmox qui portera forge, la commande crée une VM de préparation (Ubuntu,
  Docker) sur un pont qui mène à Internet, y pose le même menu que `telecharger`, rapatrie et vérifie le bundle, puis
  installe forge ici et doc, dev ici ou sur l’hôte de leurs cartes (SSH root, comme dans un cluster Proxmox). Une VM
  déjà installée est mise à jour ; relancer la commande ne retélécharge que ce qui a changé.
- Les VM Hibou restent sans Internet : seules la VM de préparation et l’hôte y accèdent.

## À savoir

- Place pour la VM de préparation : environ 2,5 fois le bundle (60 Go pour 4 Go de cartes, 300 Go pour 48 Go et plus).
- Une VM Hibou arrêtée n’est pas mise à jour : la démarrer, puis relancer.
