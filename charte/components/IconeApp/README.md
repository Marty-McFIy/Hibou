# IconeApp

Icône d'application et de dock : le symbole sur une tuile de nuit en relief (lumière du haut, coins à 22,5 % du côté). C'est le seul endroit où le symbole porte une ombre. En CSS : `Hibou.IconeApp({taille, vivante})` ; en fichier : `assets/Logos/hibou-icone-app.svg` (512 px). Sous 40 px, utiliser `hibou-favicon.svg`.
