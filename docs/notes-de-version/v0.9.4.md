# Hibou 0.9.4

_22/11/2026_

Hibou s’adapte au besoin : les deux IA, ou une seule. Détail et preuves :
[journal des corrections](../../JOURNAL-CORRECTIONS.md) (B67 à B69, F19).

## Démarrer

1. Télécharge `hibou-0.9.4.tar.gz` et `hibou-0.9.4.tar.gz.sha256` ci-dessous.
2. `sha256sum -c hibou-0.9.4.tar.gz.sha256 && tar xzf hibou-0.9.4.tar.gz && cd hibou-0.9.4`
3. Sur une machine connectée (Ubuntu, Docker) : `./hibou telecharger /chemin/du/disque`, puis `./hibou verifier`.
4. Sur les hôtes Proxmox : `./hibou installer forge`, puis `doc` et/ou `dev`. Guide complet :
   [installation](../installation.md), [mise en production](../mise-en-production.md).

## Nouveautés

- **doc et dev au choix.** Le menu demande d’abord quels serveurs d’IA déployer : les deux, doc seulement (chat,
  rédaction, documentation, recherche dans les documents) ou dev seulement (agent de code, relecture, chat avec le
  modèle de code). Seules les questions utiles sont posées, seuls les modèles utiles sont téléchargés, et forge
  s’adapte : supervision, chat, OpenCode, relecture, essai, diagnostic.
  - Sans dev : les pull requests sont toujours notifiées (ntfy) ; la relecture reste humaine.
  - Sans doc : le chat utilise le modèle de dev, sans bases de connaissances ni modèles de rédaction.
- **Archive de release** prête à l’emploi : script, miroir, charte et amorces, avec son empreinte.

## Corrections

- Le relecteur suit désormais les changements de serveurs et de profil à chaque mise à jour.
- Un modèle qui n’est plus servi (ancien profil, serveur retiré) quitte le sélecteur du chat.
- Un seul projecteur de vision (F16) est téléchargé et utilisé.

## Limites connues

- Changer de serveurs après coup : menu « Tout refaire » sur la machine connectée (nouvelles questions d’adresses).
- Profils au-delà de 4 Go, plusieurs cartes et carte de recherche : validés à blanc, à mesurer sur matériel.
